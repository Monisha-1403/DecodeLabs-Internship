# CampusConnect

CampusConnect is a responsive campus information website built using HTML, CSS, and basic JavaScript.

## Features

- Responsive navigation
- Hero section
- Upcoming events
- Event search
- Event category filters
- Interactive event details
- Campus resources section
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

The project was developed as a frontend interface to make campus events, resources, and opportunities easier for students to find.
